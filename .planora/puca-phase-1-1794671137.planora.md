# Púca Phase 1 Vitest Mutation Loop

Plan profile: greenfield
Review status: in-review
Applicable domains: backend, data, api, integrations, security, operations
Problem: Ship a source-built `puca` CLI that mutates dirty TypeScript ESM files in RAM, runs related Vitest tests on a keep-alive session, and reports survived mutants in seconds without sandbox copies, coverage maps, worker pools, or Jest.
Users: App developers running `puca` in a Vitest repo before commit; Púca maintainers building with Node >=20.6 and a Rust toolchain.
Scope: Phase 1 only as specified in `.planora/puca-phase-1-technical-solution.md`: hexagonal TS orchestrator, oxc NAPI mutator, git-dirty targeting, Vite RAM plugin, reverse import map, baseline exit 2, sequential loop, timeout respawn, schema JSON, fixtures/loop.
Out of scope: node:test register hooks; Jest; V8 coverage; warm worker pool; disk cache; CFG/type pruning; Stryker bake-off; HTML UI; @puca npm scope; platform prebuilds; puca.config.ts; Browser Mode; CJS; SFC; multi-project Vitest; .js/.mjs mutation.
Assumptions: MIT; flags only; Vitest resolved from cwd (>=4); A6 lock: git-dirty empty → exit 0 (`No files to mutate`, 0 mutants); empty --mutate → exit 2; not a git repo without --mutate → exit 2 (`Not a git repository. Pass --mutate <glob> to specify files.`); thresholds 80/60 unused for exit; no Windows gate; Clock/IDs are composition functions not ports; createRuntime({ useFakes }) dual mode using spec adapter names (not ExecGitAdapter/NapiOxcMutator).
Success criteria:
- SC-101: Given fixture source, when discover runs, then Phase 1 operator sites are recorded with offsets and mutatorName.
- SC-102: Given a site, when NAPI apply runs, then mutated source is returned in memory and no file is written.
- SC-103: Given git-dirty src/*.ts vs HEAD, when `puca` has no --mutate, then those files are candidates.
- SC-104: Given `--mutate 'fixtures/loop/src/**/*.ts'`, when puca runs, then git status is ignored for targeting.
- SC-105: Given a dirty `*.test.ts`, when targeting runs, then it is not mutated.
- SC-106: Given related tests failing unmutated, when baseline runs, then exit 2 and Vitest failure text is on stderr.
- SC-107: Given fixture mutants, when the keep-alive loop runs, then Killed vs Survived match the fixture oracle.
- SC-108: Given a source with zero related specs, when scored, then all sites are NoCoverage and no tests run for that file.
- SC-109: Given a `while (true)` conditional mutant, when outer timer fires, then status is Timeout, Vitest is respawned, and the next mutant still runs.
- SC-110: Given ≥1 Survived and 0 Error, when CLI exits, then Survived lines printed, five-bucket summary printed, exit 1.
- SC-111: Given `--json out.json`, when the run completes, then out.json validates against mutation-testing-report-schema.
- SC-112: Given `// puca-disable-next-line` above an operator, when discover runs, then that site is absent.
- SC-113: Given a full fixture run, when the workspace is walked, then no per-mutant sandbox directory and no mutated source files were written.
- SC-114: Given Browser Mode or missing cwd Vitest or missing NAPI, when puca starts, then exit 2.
- SC-115: Given the fixture’s largest source file, when parse+discover runs, then p95 is <1ms on Apple Silicon or documented CI equivalent.
- SC-116: Given cwd is not a git repo and no --mutate, when puca starts, then exit 2 and stderr is `Not a git repository. Pass --mutate <glob> to specify files.`
- SC-117: Given a clean git tree (zero eligible dirty files), when puca runs with no --mutate, then exit 0, `No files to mutate`, 0 mutants generated.
- SC-118: Given sequential mutants on calc.ts (add then subtract), when mutant 2 runs, then tests see original add (no mutant-1 leak).
Risks: invalidateFile leaks (R1); Vitest API drift (R2); barrel over-include (accepted); globalSetup respawn (specified); hang mutants (timeout specified); missing .node until build (exit 2).
Architecture decisions:
- ADR-001: Hexagonal TS orchestrator; Rust mutator behind MutatorEnginePort.
- ADR-002: Offset sites; lazy per-mutant splice apply.
- ADR-003: Resolve vitest/node from cwd.
- ADR-004: createVitest viteOverrides prepend RAM plugin.
- ADR-005: Reverse map from baseline transforms; setup/global attached to target specs.
- ADR-006: Source-first NAPI; no platform packages.
- ADR-007: mutation-testing-report-schema for --json.
- ADR-008: Git targeting via spawn shell:false.
- ADR-009: Session overlay watch/fileParallelism/maxWorkers/isolate/coverage.
- ADR-010: TestRunnerPort unexported; no register() adapter.
- ADR-011: Exit 0/1/2 as technical solution §8 + A6 lock.
- ADR-012: Oxc parser, not Babel/tsc/SWC.
Delivery strategy: Foundation repo+hexagon+fakes → Rust sites/operators/NAPI → targeting → Vitest session/map/baseline → loop/timeout → CLI/report → fixture E2E. Memory adapters before prod I/O.
Backend — Service boundaries: RunMutationSession use case; VitestTestRunner session; NapiMutatorEngine; GitDiffLocator; NodeWorkspaceFiles. Runtime: one CLI process plus one Vitest instance (respawn on timeout/crash). Failure: A6 idle exit 0; baseline/not-git/empty --mutate fail-closed exit 2; timeout respawn continue; ERROR continue then exit 2; no mutant retries. Clear plugin buffer + invalidateFile after each mutant (R1).
Data — Entities: Site, MutantResult, ReverseSpecMap, ActiveBuffer, MutationTestResult JSON. Identity: site id `{relpath}:{startOffset}:{mutatorName}:{replacement}`. Validation: UTF-8 source, oxc parse of originals. Relationships: file → sites → related specs. State: Pending → Killed|Survived|Timeout|RuntimeError|NoCoverage. Retention: in-memory per run; JSON only if --json.
API — Consumers: human CLI; optional schema JSON consumers. Operations: `puca [--mutate glob] [--json path] [--timeout ms]`. Inputs: cwd, flags, user Vitest config. Outputs: stderr/stdout lines, exit 0/1/2, optional JSON. Errors: refuse diagnostics. Compatibility: unpublished; schemaVersion 2.
Integrations — Vitest from cwd node_modules (createVitest, invalidateFile, runTestSpecifications); Git diff HEAD; Oxc via NAPI. Timeouts: outer max(testTimeout+2000, 7000) or --timeout. Degradation: missing git/vitest/napi exit 2. No network.
Security — Trust: user code executed on purpose. Controls: no mutant source on disk; hard excludes; git argv no shell; plugin swaps only active site path; isUnderCwd; missing addon fail-closed.
Operations — Node >=20.6; rust-toolchain.toml; npm run build (TS+napi); npm test; no publish/rollback matrix this cycle.
